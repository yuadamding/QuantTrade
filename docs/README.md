## Evidence boundaries

- Normative documents define intended semantics; package-owned validators and
  tests determine whether the corresponding software surface exists.
- A local checkout does not identify remote execution source. Require the
  exact source archive and manifest bound by the run.
- Kubernetes success, Ready GPUs, VRAM use, or a completed diagnostic does not
  establish reportable investment performance.
- Do not add live Job IDs, transient progress, or cluster-specific secrets to
  these repository documents.
